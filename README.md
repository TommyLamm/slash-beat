# 極意一閃：節奏打鐵 (Slash Beat)

> **極限格擋 × 隻狼式打鐵音律 × 水墨賽博武士**  
> Playroom 平台合規網頁遊戲，純前端技術打造（TypeScript + Vite + Canvas 2D + Web Audio API）。

## 遊戲介紹
玩家扮演水墨賽博孤狼劍士居於戰場中央。敵兵按音樂拍點自兩側踏步衝刺：
- **普通攻擊與飛鏢 (NORMAL / SHURIKEN)**：在命中瞬間按下 `[J]` / `[A]` / `[←]`（或點擊螢幕左側）觸發 **Perfect Parry**，爆出金屬火花巨響，削弱對手架勢值 (Posture)。
- **血紅危字直刺 (PERILOUS THRUST)**：不可防禦直刺！按下 `[K]` / `[D]` / `[→]`（或點擊螢幕右側）執行 **Mikiri Counter（看破）**，凌空踩刀踏破敵刃！
- **下段掃堂腿橫掃 (SPEAR SWEEP)**：不可格擋下段攻擊！按下 `[W]` / `[↑]` / `[Space]`（或點擊螢幕上方）執行 **Jump Counter（向上看破跳躍）**，凌空踩踏長槍雷霆劈斬！
- **居合一閃 (DEATHBLOW)**：當敵方架勢條爆滿時觸發時停高光，黑白極限反色，按下斬擊鍵即可瞬殺全屏敵陣！

## 控制方式
- **桌面端**：
  - `[J]` / `[A]` / `[Z]` / `[←]`：格擋招架 (Parry)
  - `[K]` / `[D]` / `[X]` / `[→]`：看破直刺 / 居合一閃 (Slash / Mikiri)
  - `[W]` / `[I]` / `[↑]` / `[Space]`：向上看破跳躍 (Jump Counter)
  - `[Space]` / `[Enter]`：確認 / 出陣
  - `[Esc]`：靜音切換
- **行動裝置**：
  - 點擊螢幕左半側：格擋招架 (Parry)
  - 點擊螢幕右半側：看破直刺 / 居合一閃 (Slash / Mikiri)
  - 點擊螢幕上方 35% 區域：向上看破跳躍 (Jump Counter)
  - 支援雙指多點觸控與自定義分區

## v1.2.0 重大更新亮點 (Wave 3)

### 1. 視覺反饋與特效大升級 (Juice & Visuals)
- **「雷雨天守閣」(Thunderstorm Castle) 動態天候場景**：
  - 雄偉的日式天守閣水墨城堡矗立在背景遠山前，飛簷斗拱、金色鴟尾、石垣城垛基座在電閃雷鳴中若隱若現。
  - 狂風暴雨系統：傾瀉直落的暴雨水絲隨風搖曳，打在地面激起微波水霧。
  - 閃電系統 (Lightning Flash)：天際定時劈下真實分岔樹狀電弧，背景瞬間白晝暴光，震撼映出天守閣純黑剪影！
  - 刀氣斷雨 (Blade Rain Slash)：每次格擋或看破揮刀時，中心交擊區引爆環形氣浪圈，雨滴瞬間被氣刃震散斬斷！
- **解鎖型劍氣光刃特效 (Custom Blade Trails)**：
  - 支援三種絢麗光刃樣式：
    - **蒼雷之刃 (Azure Lightning)**：青藍電弧拖尾，劈啪跳動的蒼藍雷火。
    - **猩紅煞氣 (Crimson Shadow)**：血紅煞氣拖尾，肅殺血墨狂飆。
    - **璀璨金芒 (Solar Radiance)**：金光璀璨耀眼，宛若金烏破曉。
  - 標題畫面可隨心切換光刃，連擊達到 15+ Fever Rush 或 SSS 評級時周身烈焰共鳴！
- **慢動作終結特寫 (Cinematic Slow-mo Deathblow Finisher)**：
  - 完美看破直刺或跳躍踩踏長槍擊潰強敵時，時空慢放 0.4 秒，鏡頭推進至 1.4x 慢動作特寫！
  - 瞬間觸發宣紙水墨留白濾鏡，武士與受挫敵兵化為黑白毛筆水墨剪影，只留鮮紅朱砂「看破・天誅」！

### 2. 玩法深度與機制擴展 (Gameplay)
- **全新「無盡道場試煉」(Endless Dojo)**：
  - 節奏隨擊退敵人逐步由 110 BPM 狂飆至 185 BPM，考驗真正極限反應與肌肉記憶！
  - 專屬無盡道場即時擊殺數 (Kills) 與獨立最高紀錄榜。
- **全新刺客兵種**：
  1. **雙手裏劍忍者 (Shuriken Shinobi)**：在半拍與切分音連發兩枚不同速度的旋轉飛鏢，需要連續雙按招架！
  2. **長槍僧兵 (Spear Monk)**：
     - 招式一：二段蓄力變奏直刺（槍尖金芒聚集，後撤蓄力後雷霆直刺）。
     - 招式二：下段掃堂腿橫掃（需要向上看破跳躍踩踏長槍並反斬）。
- **狂暴津輕三味線 (Tsugaru Shamisen Solo) 激情獨奏**：
  - 音樂合成器加入強勁撥子敲擊打板聲與 Sawari 共振腔，在高難度與極意狀態下爆發熱血三味線激奏！

### 3. 手感調優與 Bug 修復 (Fixes)
- **鍵位自訂與雙指操作增強**：全面支援 `[A]`/`[D]`、方向鍵 `[←]`/`[→]`、`[W]`/`[↑]`/`[Space]` 跳躍，行動端多點觸控分區更靈敏流暢。
- **修復 180+ BPM 連斬重疊雜音**：引入音訊動態壓縮器 (DynamicsCompressorNode) 與活躍語音池截斷防爆音 (Voice Stealing / Soft Fade)，確保超高速打鐵音質始終清脆純淨！
