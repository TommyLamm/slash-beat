# 極意一閃：節奏打鐵 (Slash Beat)

> **極限格擋 × 隻狼式打鐵音律 × 水墨賽博武士**  
> Playroom 平台合規網頁遊戲，純前端技術打造（TypeScript + Vite + Canvas 2D + Web Audio API）。

## 遊戲介紹
玩家扮演水墨賽博孤狼劍士居於戰場中央。敵兵按音樂拍點自兩側踏步衝刺：
- **普通攻擊 (NORMAL)**：在刀刃命中的黃金瞬間按下 `[J]`（或點擊螢幕左側）觸發 **Perfect Parry**，爆出金屬火花巨響，削弱對手架勢值 (Posture)。
- **血紅危字 (PERILOUS)**：不可防禦攻擊！按下 `[K]`（或點擊螢幕右側）執行 **Mikiri Counter（看破）**，以凌厲突刺踏破敵刃！
- **居合一閃 (DEATHBLOW)**：當敵方架勢條爆滿時觸發時停高光，黑白極限反色，按下斬擊鍵即可瞬殺全屏敵陣！

## 控制方式
- **桌面端**：
  - `[J]`：格擋招架 (Parry)
  - `[K]`：看破突刺 / 居合一閃 (Slash / Mikiri)
  - `[Space]`：開始遊戲 / 標題操作
- **行動裝置**：
  - 點擊螢幕左半側：格擋招架 (Parry)
  - 點擊螢幕右半側：看破突刺 / 居合一閃 (Slash / Mikiri)

## 授權與合規
本專案嚴格遵循 Playroom Platform 規範，零外部音訊資產，100% 程式化合成，單機或跨來源沙盒 iframe 皆可秒開運行。
