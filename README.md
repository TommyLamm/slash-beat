# 極意一閃：節奏打鐵 (Slash Beat)

> **極限格擋 × 隻狼式打鐵音律 × 水墨賽博武士**  
> Playroom 平台合規網頁遊戲，純前端技術打造（TypeScript + Vite + Canvas 2D + Web Audio API）。

## 遊戲介紹
玩家扮演水墨賽博孤狼劍士居於戰場中央。敵兵按音樂拍點自兩側踏步衝刺：
- **普通攻擊 (NORMAL)**：在刀刃命中的黃金瞬間按下 `[J]`（或點擊螢幕左側）觸發 **Perfect Parry**，爆出金屬火花巨響，削弱對手架勢值 (Posture)。
- **血紅危字 (PERILOUS)**：不可防禦攻擊！按下 `[K]`（或點擊螢幕右側）執行 **Mikiri Counter（看破）**，以凌厲突刺踏破敵刃！
- **居合一閃 (DEATHBLOW)**：當敵方架勢條爆滿時觸發時停高光，黑白極限反色，按下斬擊鍵即可瞬殺全屏敵陣！

## 控制方式
- **桌面端**：
  - `[J]`：格擋招架 (Parry)
  - `[K]`：看破突刺 / 居合一閃 (Slash / Mikiri)
  - `[Space]`：開始遊戲 / 標題操作
- **行動裝置**：
  - 點擊螢幕左半側：格擋招架 (Parry)
  - 點擊螢幕右半側：看破突刺 / 居合一閃 (Slash / Mikiri)

## v1.1.0 重大更新亮點
- **全新 Boss 專屬對決關卡「影之劍聖」(Shadow Kensei)**：
  - 具有多段節奏變速連斬（三連斬、變速五連斬、延遲重刀、躍空突刺）。
  - 專屬紫煞妖氣殘影與高難度節奏考驗，破防時觸發史詩級「影之奧義處決」！
- **極致手感與水墨視覺反饋 (Juice & Visuals)**：
  - Perfect Parry 金紅高溫火花與水墨筆觸飛白噴濺。
  - 浮世繪風格背景裝飾：飄落的櫻花花瓣與水墨竹葉，狂暴連擊時背景竹林隨刀風劇烈搖曳。
  - 「危」字印記以血紅印章蓋下、伴隨高音金屬錚鳴；看破 (MIKIRI) 凌空踩刀，鏡頭瞬間縮放帶慢動作特寫！
  - 連擊極意境界 (Fever Rush)：15+ Combo 主角周身環繞蒼藍烈焰，得分倍率暴增。
- **音律系統與玩法擴展 (Gameplay)**：
  - 標題畫面新增「節奏延遲校準模式」(Latency Calibration)：提供視覺節拍器與滴答音，支援手動微調補償 (±150ms)。
  - 音樂引擎升級：雙八度日本陰旋法/都節音階古箏琶音、大太鼓與締太鼓雙層次鼓點、完美招架共振和弦、失誤斷音反饋。
- **手感與穩定性修復 (Fixes)**：
  - 修復高速連點招架鍵可能產生的空刀冷卻卡頓與吃指令問題，手感完美貼合《隻狼》打鐵順滑度。
  - 全方位優化 AudioContext 狀態恢復與觸控喚醒邏輯，確保行動端無延遲開播。
